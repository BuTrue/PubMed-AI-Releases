# PubMed AI v0.5.4

新增 PubMed 检索教程、缓存目录切换迁移、小绿鲸 Token 隐私改进。

## 新增

- 帮助中心新增「检索教程」：关键词、MeSH 主题词、字段标签、布尔组合、逐步示例与常见错误。
- 设置 → 缓存显示当前缓存目录；可切换到新目录，保存时自动迁移检索缓存与翻译缓存，旧目录保留备份。
- 小绿鲸 Token 不再回显明文；留空保存保留旧 Token，粘贴新值会清理首尾/内部空白与 Bearer 前缀，清除按钮同时删除本机会话。

## 说明

- 公开版本不预置受版权限制的期刊分区/影响因子数据。
- 遇到 NCBI 429 时程序会退避并自动切换 Europe PMC；配置 NCBI API Key 可减少限流。

## 下载

- `PubMedAI-Setup-v0.5.4.exe`：推荐，覆盖安装旧版本，用户数据保留。
- `PubMedAI-Portable-v0.5.4.exe`：单文件免安装版。
- `SHA256SUMS.txt`：校验文件。
